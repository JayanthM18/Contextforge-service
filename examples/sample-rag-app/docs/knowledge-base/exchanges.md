# Exchanges

An exchange is a return and a new order handled together, so the same 30-day
window described in `returns-and-refunds.md` applies.

## Same product, different size or colour

Choose *Exchange* rather than *Refund* in the Returns Centre and pick the
replacement variant. The replacement ships as soon as the return label is
scanned by the carrier, so you are not waiting for the warehouse to receive the
original. This is called an advance exchange and it is available once per
order.

If the returned item never arrives within 21 days of the label being scanned,
the replacement is charged to the original payment method at the price you
originally paid.

## Different product

A swap to a different product is handled as a refund plus a fresh order. Refund
the original through the Returns Centre, then place the new order yourself. Any
price difference is settled at current prices; we do not honour the original
order's price on a different product.

## Exchange shipping cost

Exchanges ship free by Standard delivery within the country of the original
order. Upgrading the replacement to Express costs the usual Express fee. We do
not exchange across borders — an order placed in Canada cannot be exchanged for
delivery to the United States.
