# Accounts and signing in

An account is not required to place an order — guest checkout is available —
but it is required to use the Returns Centre, track orders and hold loyalty
points.

## Resetting a password

Choose *Forgot password* on the sign-in page. The reset link is valid for **60
minutes** and can be used once. Requesting a new link immediately invalidates
the previous one. If the email has not arrived within 10 minutes, check the
spam folder and confirm you are using the address the order was placed with.

## Two-factor authentication

Two-factor authentication is optional and uses an authenticator app; we do not
send codes by SMS. Enabling it invalidates existing sessions on other devices.
Recovery codes are shown once at setup and cannot be retrieved later — losing
both the authenticator and the recovery codes means identity verification with
support, which takes up to 5 business days.

## Changing the email address

The account email can be changed in Account Settings and requires confirmation
from both the old and the new address. Orders already placed keep the old
address on their records, so dispatch notifications for an in-flight order go
to the address that was current when it was placed.

## Closing an account

Closure is requested in Account Settings. See `privacy-and-data.md` for what is
deleted and what is retained.
